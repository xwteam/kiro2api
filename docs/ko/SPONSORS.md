# ☕ 후원 & 기여

도움이 되셨나요? 작성자에게 커피를 사주거나 WeChat 그룹에 가입하여 지원을 받으세요. QR 코드는 [관리 패널 대시보드](../../README.md)에서 확인할 수 있습니다.

---

## 💖 프로젝트 지원

kiro2api는 주로 개인이 유지 관리하는 오픈 소스 프로젝트입니다. 이 프로젝트가 도움이 되었다면 다음과 같은 방법으로 지원해 주세요:

- ⭐ 프로젝트에 스타 주기
- 🔗 필요한 친구들과 공유하기
- 🐛 버그나 제안을 [Issue](https://github.com/xwteam/kiro2api/issues)로 제출하기
- 🔧 코드나 문서를 PR로 기여하기

---

## 📢 커뮤니티 그룹

WeChat 그룹에 가입하여 사용 도움말, 경험 공유, 새로운 기능 논의를 받으세요. 관리 패널 대시보드의 QR 코드를 스캔하여 가입할 수 있습니다.

---

## 🤝 기여하기

1. 이 저장소를 포크하기
2. 브랜치 생성 `git checkout -b feature/your-feature`
3. 코드 커밋 `git commit -m "feat: add something"`
4. 푸시 및 풀 리퀘스트 생성

**기여 분야:**

- 🔑 토큰 자동 갱신 및 계정 풀 안정성 개선 (single-flight 갱신, 분급 쿨다운, body-aware 실패 분류 개선 아이디어 환영)
- 🔀 엔드포인트 회귀 및 계정 간 재시도 로직 강화 (Kiro / CodeWhisperer / AmazonQ)
- 🔌 다중 프로토콜 호환성 개선 (OpenAI / Anthropic / OpenAI Responses / Gemini)
- 🌐 다국어 번역 개선
- 📱 관리·사용자 패널의 모바일 적응 최적화
- 🧪 새로운 Claude 계열 모델 어댑테이션 및 호환성 테스트
- 📖 문서 개선
