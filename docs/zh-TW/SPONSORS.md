## 🤝 參與貢獻

1. Fork 本倉庫
2. 建立分支 `git checkout -b feature/your-feature`
3. 提交程式碼 `git commit -m "feat: add something"`
4. 推送並建立 Pull Request

**貢獻方向：**

- 🔄 令牌自癒與帳號池策略（單飛刷新、分級冷卻、負載均衡優化，歡迎有經驗的開發者貢獻思路）
- 🔀 端點回退與跨帳號重試的失敗分類調校（Kiro / CodeWhisperer / AmazonQ）
- 🔌 多協議相容性完善（OpenAI / Anthropic / OpenAI-Responses / Gemini 四協議互通）
- 🧪 新模型適配與相容性測試
- 🌐 多語言翻譯完善
- 📖 文件改進
