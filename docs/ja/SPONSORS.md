# ☕ サポート & 貢献

役に立ちましたか？作者にコーヒーをおごるか、WeChatグループに参加してサポートを受けてください。QRコードは管理パネルのダッシュボード、または[リポジトリトップ](../../README.md)にあります。

---

## 💖 プロジェクトをサポート

kiro2apiは主に個人によって維持されているオープンソースプロジェクトです。このプロジェクトがお役に立った場合は、以下の方法でサポートをご検討ください：

- ⭐ プロジェクトにスターを付ける
- 🔗 必要としている友人と共有する
- 🐛 バグや提案を[Issues](https://github.com/xwteam/kiro2api/issues)で報告する
- 🔧 コードやドキュメントをPRで貢献する

---

## 📢 コミュニティグループ

WeChatグループに参加して、使用方法のヘルプ、経験の共有、新機能の議論を行ってください。管理パネルのダッシュボード、または[リポジトリトップ](../../README.md)のQRコードをスキャンして参加できます。

---

## 🤝 貢献する

1. このリポジトリをフォークする
2. ブランチを作成する `git checkout -b feature/your-feature`
3. コードをコミットする `git commit -m "feat: add something"`
4. プッシュしてプルリクエストを作成する

**貢献分野：**

- 🔄 トークン自己修復・アカウントプールの安定化（有効期限切れ時の自動リフレッシュ、単一飛行協調、失敗分類と段階的クールダウンの改善アイデアを歓迎）
- 🔀 エンドポイントフォールバック（Kiro / CodeWhisperer / AmazonQ）とクロスアカウントリトライの強化
- 🔌 マルチプロトコル互換性（OpenAI / Anthropic / OpenAI-Responses / Gemini）の改善とエッジケース対応
- 🌐 多言語翻訳の改善
- 🧪 新しいモデルの互換性テストと適応
- 📖 ドキュメントの改善
