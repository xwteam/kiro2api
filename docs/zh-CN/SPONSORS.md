## 🤝 参与贡献

1. Fork 本仓库
2. 创建分支 `git checkout -b feature/your-feature`
3. 提交代码 `git commit -m "feat: add something"`
4. 推送并创建 Pull Request

**贡献方向：**

- 🔄 令牌自愈与账号池策略优化（单飞刷新、分级冷却、跨账号重试的边界打磨）
- 🔀 端点回退健壮性（Kiro → CodeWhisperer → AmazonQ 的失败分类与切换逻辑）
- 🔌 多协议兼容完善（OpenAI / Anthropic / OpenAI-Responses / Gemini 四协议的转换与工具透传）
- 🧪 新模型适配与兼容性测试（随订阅档位授权的模型接入）
- 🌐 多语言翻译完善
- 📖 文档改进
