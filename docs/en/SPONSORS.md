## 💖 Support the Project

kiro2api is an open-source project maintained primarily by an individual. If this project helps you, consider supporting it through:

- ⭐ Star the project
- 🔗 Share with friends who might need it
- 🐛 Submit [Issues](https://github.com/xwteam/kiro2api/issues) to report bugs or suggestions
- 🔧 Submit PRs to contribute code or documentation

## 🤝 Contributing

1. Fork this repository
2. Create a branch `git checkout -b feature/your-feature`
3. Commit code `git commit -m "feat: add something"`
4. Push and create a Pull Request

**Contribution Areas:**

- 🔑 Token keep-alive & self-healing improvements (single-flight refresh, cross-account retry, failure classification — experienced developers welcome to contribute ideas)
- 🔀 Multi-protocol compatibility (OpenAI / Anthropic / OpenAI-Responses / Gemini adapter parity)
- 🧪 New model adaptation & compatibility testing (as Kiro subscription tiers expand)
- 📱 Mobile adaptation optimization for the `/admin` and `/user` panels
- 📖 Documentation improvements
